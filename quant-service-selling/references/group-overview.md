# A 股量化接单工作群 · 总览

> 按 AgentWork 社区规范组织：真场景 · 真过程 · 真结果 · 真边界
> 一项任务跑通后沉淀成可复现的 Case、Skill 和工作流。

## 这个工作群解决什么问题

把「我会这些技术」变成「有人愿意为结果付钱」。

## 三个技能的分工

```
[客户来问 / 想接单]
    │
    ▼
quant-data-doctor ──── 免费诊断数据问题
    │                （建立信任，不是成交手段）
    │ 客户看到问题后自己算价值 → 他问了
    ▼
quant-service-selling ── 报价 + 异议处理 + 三平台文案
    │                    （把技术翻译成商品）
    │客户签了
    ▼
onequant-deploy-kit ──── 交付：环境自检 → 搭建 → 验收
                         （保证跑得起来、有人负责）
```

### quant-data-doctor ·数据诊断
**触发**：「我的回测可信吗」「数据有没有问题」
**产出**：七项体检报告（完整性/静默失败/单位归一/复权/幸存者偏差/停牌涨跌停/前视偏差）
**关键点**：数据不对时回测结果一定是错的，而且**看起来完全正常**。

### quant-service-selling · 报价与获客
**触发**：「这些能卖多少钱」「怎么发闲鱼/小红书」
**产出**：六项标准服务报价表 + 异议处理话术 + 三平台文案模板
**关键点**：客户买的是「客户能看到的结果」，不是技术描述。

### onequant-deploy-kit · 部署交付
**触发**：「怎么在客户机器上搭一套」「私有化怎么做」
**产出**：环境自检表 + 故障排查决策树 + 验收清单 + 7 天交付流程
**关键点**：交付的不是软件，是「跑得起来且有人负责」。

## 与已有技能的衔接

工作群里已有的量化技能（数据获取、回测、决策辅助、散户观测）解决**技术问题**；
这三个新技能解决**变现问题**。互补关系，不是替代。

| 需要做的事 | 用哪个 |
|---|---|
| 拉数据、修管道 | `a-stock-data-pipeline` |
| 跑回测、验因子 | `quant-batch-backtest` |
| 今天该不该买 | `quant-daily-advisor` |
| 看散户行为信号 | `散户行为观测` |
| **客户数据有没有问题** | **`quant-data-doctor`** |
| **这些能卖多少钱** | **`quant-service-selling`** |
| **怎么交付给客户** | **`onequant-deploy-kit`** |

## 核心认知（务必先读）

1. **技术不是商品，结果才是。** 「精通多源降级」卖 2000，「接口挂了自动切备用源」也卖 2000——但后者客户听得懂。

2. **能被自动化的只有「怎么做」，不能被自动化的是「该不该这么做」和「出了事谁负责」。** 客户付钱买的是后者。

3. **开源是获客渠道，不是商业模式。** Postiz 33k star、$170k MRR、零广告预算。Nevo David 之前花 $3000/月买 SEO 没用，开源后靠同步发布跑起来。

4. **企业价和个���价是两个数字。** 个人 ¥3000 要犹豫，企业 ¥9999 走审批就行。

5. **第一个客户的价值 >> 第 10 个客户。** 先跑通闭环，别先搭工具。

## 真实边界（不可承诺）

- ❌ 不承诺任何策略收益率
- ❌ 不保证公开数据源 100% 可用（官方也会调整）
- ❌ 不做代客炒股、不碰客户资金
- ❌ 不用脚本/群控操作任何平台账号
- ✅ 保证数据管道可维护、故障可恢复
- ✅ 保证交付物在约定范围内可运行
- ✅ 交付后 7 天质保
