# 量化能力商品化 · 报价与获客

## 何时用

- 用户问「我做的这些东西能卖多少钱」
- 用户要写报价单、服务清单、报价方案
- 用户要发闲鱼 / 小红书 / 雪球 / 朋友圈的获客文案
- 用户说「没人愿意把赚钱办法写出来」「我的东西垃圾」

## 核心前提：技术不是商品，结果才是

用户最大的误区是「我的代码不如开源项目，所以不值钱」。必须先校正：

| 判断 | 事实 |
|---|---|
| 「代码质量决定价值」 | 不相关。Postiz 33k star，代码本质是社交平台 API 封装层 |
| 「开源=免费=赚不到钱」 | 开源是**获客渠道**。Nevo David 靠开源做到 $170k MRR，零广告预算 |
| 「我的东西不够好」 | 商业价值只看三问：多少人真在用 / 他们为什么搞不定 / 他们付过多少钱 |

**代码质量只是让上面三条成立的必要条件，不是卖点。**

## 第 1 步：能力商品化（把技术翻译成「客户能看到的结果」）

### 转换公式

```
❌ 技术描述：精通 pytdx 批量接口与多源降级
✅ 结果描述：接口挂了自动切备用源，成交量单位统一，历史数据不再错乱
```

**规则：客户只关心两件事——他现在有什么麻烦、你能不能让他没有。**

### 六项标准服务（A 股量化）

| 服务 | 参考价 | 客户看到的结果 | 工时 | 难度 |
|---|---|---|---|---|
| 策略有效性回测报告 | ¥1,500 | 指定策略在真实历史上的胜率、夏普、最大回撤，换手率和单调性体检 | 6h | 中 |
| 数据源故障修复 | ¥2,000 | 接口挂了自动切备用源，成交量单位统一，历史数据不再错乱 | 4h | 低 |
| 每日决策辅助回放 | ¥3,000 | 回放到任意历史某天，看当时系统会给出什么建议，建议对不对可以核对 | 10h | 中 |
| A股本地数据库搭建 | ¥5,000 | 自己电脑每天自动更新全市场行情，历史可回溯，不再依赖会崩的在线接口 | 12h | 中 |
| 私有化行情终端部署 | ¥12,000 | 内网自建行情终端，数据不出公司，同事都能用 | 30h | 高 |
| 量化环境整体代搭 | ¥20,000 | 从零到能跑策略的完整环境，含数据、框架、回测、模拟盘，含培训 | 50h | 高 |

**定价原则**：
- 新手起步挂**小单**（1500-5000），先跑通「接单→报价→交付→验收→结单」闭环
- 不要一上来接 12000+ 的大单——你需要先有案例
- 不做 SaaS 订阅：散户的付费心理是「亏钱可以，工具收费不行」

## 第 2 步：报价的三条硬规矩

### 规矩一：先收钱再开工

不接受「先做出来看看效果」。免费方案只能给到**诊断报告**级别，不给完整交付。

### 规矩二：报价按「客户省了多少」算，不按「我花了多少小时」算

- 客户自己搭环境：3-5 天
- 你搭：1 天
- 客户省 4 天 → 报价 5000 而不是 2000（他省了 4 天的价值）

### 规矩三：企业价与个人价是两个数字

个人用户 ¥29 要犹豫，**企业 ¥9,999 走审批就行**。所以：
- 小额服务：2000-5000（个人/散户）
- 大额服务：1-5 万（工作室/小机构）

## 第 3 步：异议处理话术

| 客户说 | 回应 |
|---|---|
| 「这个你自己也能搞吧」 | 我知道您能，但不是能不能，是您的时间值不值。您有更重要的事要做，这部分我替你做。 |
| 「太贵了」 | 现在的行情，工具免费是因为没人肯为「跑通」负责。这价格买的是「坏了有人管」。 |
| 「我先试试别的」 | 可以。试完如果数据对不上，随时来找我，我帮您看问题出在哪。 |
| 「能不能便宜点」 | 价可以商量，范围不能缩。要降价的话，我把交付范围从「装好+教会」缩到「只装好」。 |

## 第 4 步：三平台文案模板

### 通用结构（四个部分，缺一不可）

1. **真实痛点** — 用客户自己的语言，不用技术词
2. **你能解决的** — 具体到场景，不是能力形容词
3. **交付什么** — 明确边界，减少纠纷
4. **信任凭证** — 截图、案例、真实数据

### 咸鱼版（避免敏感词与站外引流）

```
标题：A股数据自动更新 | 本地部署一次配置长期用

痛点：每天手动更新数据太慢？接口第二天就崩？历史数据查不到？

我做的：
· 全市场行情每天自动更新，历史数据本地留存可回溯
· 多数据源自动切换，接口挂了不影响
· 成交量单位已归一，回测不再算错

交付：数据源配置 + 每日自动更新 + 历史回溯 + 一次远程调试
周期：3-5 天

【图：通达信风格终端真实截图】
```

⚠️ 闲鱼红线：
- 聊天里**绝不**发微信/手机号（永久封号高压线）
- 不写「课程」「网盘」等词（易限流）
- 闲鱼用户是冲便宜货来的，挂**99 元咨询费**引流，成交后平台内深谈
- 全程平台内沟通交付，用远程操作，不引导私下交易

### 小红书版（吃长尾搜索流量）

```
标题：A股量化避坑｜这5个数据坑我全踩过了

1. akshare 更新到某天就断，第二天数据全空
2. pytdx 批量接口会「静默返回空」，不报错但没数据
3. 成交量单位（手/股）不归一，回测结果全偏
4. 逐只串行拉数据，5000 只需要 3 小时
5. 数据不全时回测照样出结果，看着挺漂亮

第 3 个坑最隐蔽——单位错了回测依然能跑，
但你的胜率完全是假的。

#量化 #A股 #股票 #量化交易 #避坑 #回测
```

### 雪球版（专业向，可信度优先）

```
我这两年在自建 A 股本地数据环境，踩了些坑，
整理出来给同样在折腾的朋友：

问题：数据源的脆弱性比想象中严重
· 单一接口断供 → 必须有备源和降级
· 批量接口不可信 → 部分接口会返回空但不报错
· 数据完整性必须每日校验，不能等到回测才发现

建议的最低验证：
1. 每日检查每个交易日的记录数是否正常
2. 成交量单位是否归一
3. 用一个已知结论的策略做交叉验证

数据不对时，回测结果一定是错的，而且看起来完全正常。
```

## 第 5 步：自动化的边界（不要做的事）

用户常问「能不能自动发闲鱼/自动转发」。必须明确劝阻：

| 做法 | 后果 |
|---|---|
| 群控/多账号脚本操作 | 实测：正常运营号日曝光 8000-12000，群控号三天掉到几百 |
| Playwright 逆向闲鱼 | 实测「刚上线两小时小号就被封 7 天或永久限流」 |
| 自动私信/自动下单 | 属高风险黑产行为，风险成倍放大 |
| 交出账号 Cookie 给第三方工具 | 登录信息泄露风险 |

**风控查五个维度**：设备指纹、行为时序、IP 信誉、内容重复度、反导流模型。
**风控不看你是买还是卖，用脚本就是违规。**

## 第 6 步：认知误区校正（用户说这些话时必读）

### 「软件付费的时代过去了」

部分为真，但混了两件事：
- **「做软件卖订阅」这个动作**确实死了——供给爆炸，免费替代多
- **「有人愿意为结果付钱」这个事实**没变——Postiz $170k MRR 是 Stripe 实测快照

真正变化的是：**软件变便宜了，所以卖软件死了；卖结果变得值钱了。**
证据：n8n 一个自动化单 $500-2000，而一堆 AI 生成的待办 App 送人都没人用。

### 「没有别人真实的赚钱办法走不通」

**这句话在游戏打金领域成立，在其他领域不成立。**

AgentWork 社区（AlephAITech）公开了 WorkBuddy 实战蓝皮书 3.3k star / 478 fork、49 篇指南、31 个真实任务，全部开源。**能赚钱的方法确实有人公开写，而且大量公开写。**

稀缺的不是方法，是「把方法跑通并且愿意写出来的人」——这个比例极低。

### 「游戏打金能赚钱」

数据（三年从业者实测）：
- 单台机器日收益 **25-40 元**（注意：这是好情况）
- 稳定运营超 1 年的工作室**只占进场者的 2%**
- 月封号率超 20% 必亏
- 「零门槛日入过百」的新服，最多做 1 天就要撤（有人 24 个号封了 21 个）

**核心问题**：日收益 40 元 × 30 天 = 1200 元，还不如一个数据修复单。

### 「我也是用 AI，那别人为什么要找我」

这问题问对了，但答案是反的：

**能被自动化的只有「怎么做」。不能被自动化的，是「该不该这么做」和「出了事谁负责」。**

客户付钱买的三个东西：
1. **已踩过的坑** — 「akhare 昨天还好好的」这种问题查不到，答案在降级代码里
2. **敢下判断** — 数据不全时该修数据还是改策略，调用户自己决定不了
3. **替他扛责任** — 出了问题是你的事，这买的是确定性不是技术

**这三样 AI 一样都没有。** AI 没有跑过几年实盘，不了解他的业务，也不可能承担责任。

### 「我的东西比开源项目垃圾」

用这三个问题体检，不用看代码：
1. 有多少人真的在用？（不是 star，是「不上线就出事」的依赖）
2. 他们为什么自己搞不定？（必须是他试过、踩过、放弃了）
3. 他们为结果付过多少钱？（哪怕一块钱，无法伪造的信号）

**当前状态：1 人 / 0 元。** 这不是技术问题，是分发问题——**而分发是可以解决的。**

## 第 7 步：第一个客户的验证（成本为零）

不要先搭工具，先做这个：

**找 3 个真实的散户或小工作室，问三个问题：**
1. 你现在用什么看行情/跑策略？
2. 上次数据出问题是什么时候，怎么解决的？
3. 如果有人帮你把数据源修好、自动化跑起来，你愿意花多少钱？

如果 3 个人里有 1 个说「愿意花 2000」→ 第一单今天就能成。
如果一个都没有 → 需求判断错了，调方向，但这个结论是真的，不是猜的。
